公开部署说明： 本页描述维护端本地采集工具。GitHub Pages 是静态快照站点，不执行 Python 爬虫；公开仓库不包含原始PDF/网页存档。网页按钮仅重新加载已发布版本。

自动化与数据质量

使用

交付包根目录双击 start-dashboard.cmd：启动只监听127.0.0.1的本地看板，默认8765端口。按钮“采集并更新”执行真实采集、规范化、检验和看板生成，完成后重载；进程保持打开时每24小时更新一次。关闭进程即停止，不安装系统服务、不注册计划任务。端口冲突可用 python scripts/serve_dashboard.py --port 8766。命令行无浏览器模式用 --no-browser；禁止周期更新用 --interval-hours 0。

不运行服务也可直接打开 dashboard.html，包含全部数据，无CDN/网络依赖；它是离线快照，按钮会提示如何运行更新，不假装刷新。一次性更新运行包根目录 powershell -ExecutionPolicy Bypass -File update.ps1。换机器先 python -m pip install -r requirements.txt。当前机器依赖已就绪。

collect_public.py：公开GET，3并发、每个请求最长40秒读超时、最多3次重试；SEC顺序请求。失败记录URL/时间/错误；不绕过登录/验证码，不无限重试。JS动态页先寻找官方API、站点地图和附件；CoreWeave动态页面目前仅存档，财务改用SEC结构化数据。未配置Wind、富途未连接不妨碍这条公开源管线。

build_data.py --as-of YYYY-MM-DD：规范口径；默认本机日期。初次演示截止2026-10-21。API价格只能视为采集时快照，不能用这个参数制造过去价格。历史事实从官方带日期公告恢复，保存“期间、发布日期、抓取时间”三种时间。公告时分未核验，事件研究统一下一交易日收盘起算。跨期口径变化、语义不明的数据进复核队列。

test_hypotheses.py：输出逐事件与全期限/全基准统计。build_dashboard.py：嵌入数据生成离线HTML。所有脚本相对Skill根目录寻址，拷贝目录后可用。服务刷新错误保留旧HTML，在按钮状态和data/update.log显示失败；数据中间文件可能已更新，修复后应完整重跑四步，不能混用不同次运行的中间产物。

数据层和可审计性

  • data/raw/{sha256}.*：原始字节快照，内容不变不重复存；PDF逐页文本另存。同一URL改版产生新哈希，旧快照保留。
  • data/runs/：每次运行来源清单；sources.json是最近一次采集状态。
  • observations.json：指标/实体/单位/口径/实际或指引/期间/发布日期/抓取时间/URL/哈希/原句/页码。
  • review-queue.json：自动发现但不能可靠解释的文本。历史NBIS ARR采用已审阅哈希+页码+短锚；新季度不会靠宽泛关键词直接入库。需新增并验证选择器，保留人对财务语义的复核。这部分是辅助自动化，不是无人值守的财报理解。
  • sec-facts.json：保留全部抓取到的财务标签期间与申报版本；看板选最新期间的最新申报值，不是时点回测数据库，不得用于未经vintage筛选的回测。
  • prices.json：Yahoo调整后日收盘，剔除截止日当日；供应商调整和历史修订风险未消除。IPO/恢复交易之前不补价格。
  • event-study.json：实际检验结果；将旧网页恢复的历史称为回溯重建，不能声称已具备真正point-in-time数据。以后新增快照才有前瞻归档证据。

在页面上同时查看披露日期与抓取日期：今天成功抓取不代表经营数据更新到今天。已采集的12类指标均为部分覆盖；例如现金不是完整资金缺口，电力指引不是已计费MW。数据量大也不提高缺失关键变量的可信度。

M02其他模型商收入 尚未接入；接OpenAI官方商业更新、上市模型商IR；如只在媒体采访出现，存媒体原文与说话时间 未核原话不冒称一手；不可用融资额代收入
M03付费工作量 NBIS Token Factory “>3x”有披露但无付费分拆；下一步OpenRouter公开排名快照、公司披露使用量 平台样本代理，免费量与行业总量不可等同
M04有效API价 OpenRouter模型API自动取输入/输出标价，后续接各厂商价格表与缓存/批量折扣 缺合同净价；保留模型ID和渠道。无历史快照就不能回测历史降价
M05资本开支 SEC四大云商现金PP&E，自动更新 非AI专属，YTD与季度分开；下一步财报电话会指引标注管理层估计
M06合同/收入 SEC RPO + NBIS实际ARR RPO、backlog、ARR三条独立序列；合同附件和履约条款需进一步解析
M07电力 NBIS年底签约电力指引已核验；下一步爬项目建设/电网排队/公司里程碑 电网申请不等通电；需项目ID、日期、阶段一致的滚动台账
M08租价 Lambda官网HTML按配置行抓取 公开标价代理；同卡型/网络/内存/期限才比较。成交净价需授权合同或供应商询价记录
M09 GPU交付 缺失；IR演示材料与采购/交付公告附件，项目验收证据 订单、到货、部署、客户验收分别建状态，不从MW硬推已交付GPU
M10资金缺口 SEC现金只是输入；补债务到期表、受限现金、未提款额度、capex承诺 缺项留空/区间；不能以现金余额宣称“资金充足”
M11集中度信用 缺失；10K/20F/6K客户集中度脚注、合同与客户财务 有时仅匿名客户；不猜测名称，不混RPO与收入集中度
M12代际TCO 缺失；GPU供应商规格+整机配置+租价快照，采购净价来自授权合同 规格可爬，真实采购折扣不可凭空推定
M13利用率 缺失；IR披露/授权调度计费日志 供给可用性/网页“售罄”只是供需代理，不能变为95%利用率
M14缓存/IO 缺失；客户授权API日志或公开可复现任务集 受客户和任务分布影响；不能用单次benchmark代表行业
M15吞吐 缺失；公开基准原始结果/供应商说明，记录GPU、并发、精度、SLA 测速会消耗付费API时另按用户授权执行；当前不付费压测
M16利润 NBIS调整后EBITDA只是代理；分部损益/模型商推理披露 不能改称推理毛利；无训练/总部成本时不叫净利润
M17预付款 SEC当前合同负债+NBIS预付款年度指引 合同负债是存量，预收是现金流；保留指引/实际区别
M18资金成本 SEC流动债务部分+NBIS一笔贷款SOFR价差 尚无完整债务表和WACC；下一步逐笔贷款期限/担保/费用
M19折旧残值 缺失；财报PP&E会计政策脚注+旧代GPU同配置租价持续快照 租价跌幅不等残值跌幅，经济寿命与会计寿命不同
M20软件留存/SLA 缺失；官方状态页RSS/API、公开SLA和发布日志 可自动采故障频率，不能替代客户留存/NRR，需公司披露
M21替代竞争 缺失；云商自研芯片公告/部署披露、模型商硬件合作 硬件可用性与采购份额不同，供应关系要证据
M22每成功任务成本 缺失；公开任务基准与可复现评测，匹配定价快照 统一任务成功率/延迟条件；价格低不等有效成本低
M23采用/预算 缺失；企业官方部署披露、定期调查原始问卷/口径 调查样本代理，不爬网站访问量冒充付费预算
M24训练研发 缺失；财报R&D分项、模型训练报告 公开研发包括多个项目，不硬拆训练现金成本
M25电价/PUE 缺失；公用事业费率表、项目环境许可/公司设施数据 费率表与实际购电合同价不同；额定PUE与实际不同
M26标准化分部 部分SEC集团财务+2个已核同口径增长 IREN含矿业；NBIS出售Toloka，不拼接不同集团范围
M27估值资本结构 股价已采但未形成完整EV；补股数、双层股权、可转债、非核心投资 不以自由流通股数代总股本；EV不能只加流动债务
M28循环融资 缺失；监管13D/13G与关联交易脚注及采购投资联合公告 金融投资与客户收入分开，不自动认定虚假收入
M29政策/地域 缺失；BIS等监管官方公告、公司地区收入脚注 记录生效日，不以新闻发布日期替代
M30预期/事件 公告日期已恢复；历史一致预期缺失，需授权供应商vintage或自建事前预测快照 不得从事后研报回填“当时一致预期”；无它就不声称测试surprise

公开源足以做持续监测，但净价、利用率、客户信用和真实预期往往是机构研究的差异化数据，爬虫不是消除这些信息壁垒的万能工具。当前缺口明确呈现在看板，而不是人工填入估计值伪装自动化成果。
