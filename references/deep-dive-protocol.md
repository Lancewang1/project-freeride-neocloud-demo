# 深度案例：探索性检验登记（2026-10-22）

本扩展由用户提出后新增，全部属于探索性检验，没有样本外验证。查看计算结果前固定以下口径。

- Anthropic：官网全新闻 sitemap 扫描；公司整体 run-rate 的新高披露构成主事件集，重复、历史回溯、Claude Code 单产品、预测分别保存但不混入主集。媒体补充历史单列，首次披露日未经证实不纳入主检验。
- 样本股票 CRWV、NBIS、IREN；基准 QQQ、SMH；窗口1、5、20交易日全部报告。非交易日映射下一交易日。已知盘后财报用当日收盘作为基点；公告时间不明确时用披露日前一交易日收盘至下一交易日收盘作为宽窗口的1日反应，不能称为可执行策略收益。
- 市场模型用事件前120至21交易日拟合，至少40条；不足则保留基准相减、不估 beta。报告原始收益、基准相减、市场模型异常收益及训练样本数。事件期实际收益与模型预期收益均用逐日复利，CAR为两者差。
- 敏感度分别定义为事件绝对异常收益、以事前残差波动率标准化的异常收益；不把事后最大反应称为结构性弹性。连续至少4个事件才能计算增长幅度与反应的Pearson/Spearman相关。下界run-rate按阈值计算的增长只是一项敏感性代理，不是精确增长。
- CRWV：六个上市后季度，分析RPO、backlog、收入、active MW、EBITDA利润率、CFO/收入和现金capex/收入的变动与后续股价。RPO以可核查首次SEC申报日期，backlog/其他财报指标以公司新闻时间。口径变动不隐藏；季度现金流由同年YTD差分。
- 不能对上升的指标水平与股价水平直接回归宣称因果。增长/变化数据用于相关检验；财报包含利率、指引、融资及其他消息，单因素无法分离。RPO份额无可比行业分母时不计算假份额或其相关系数。
- 精确双侧置换p值；对同一指标的所有股票×基准×窗口检验做Holm校正；留一法和按日期前后分组只作为脆弱性检查。不得择优挑选窗口或将零假设未拒绝说成已证明没有关系。
- 不对缺失财报/缺失回报填零，不对ARR做日频插值后制造样本量。历史网页为当前抓取的原披露重建，不能保证严格PIT存档。

估值采用2026-10-21收盘价；财报按最近公开期间，预测保留供应商和更新时间。反推增长是给定资本结构、利润率、退出倍数和要求回报的条件解，不称为市场一致预期。现金表将已披露偿付日程和研究者预测分开；CFO口径不再重复减利息、经营租金或重复加客户预付款。
