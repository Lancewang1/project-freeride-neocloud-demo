# 框架逻辑审计与数据配合

## 审计结论与标准

**结论：原框架是较好的产业尽调目录，尚不能称为经过验证的股票预测模型。** Bernstein 的十维比较帮助识别公司差异；Goldman 的采购/BOM 框架帮助解释价值链。它们不提供跨周期统计验证、统一权重或可机械交易的阈值。把券商研究目录称为“顶级对冲基金模型”缺少依据。

这里采用 FREERIDE 自定的机构研究验收标准，不冒称任何机构认证：①可追溯的一手数据与口径；②能被反证的经济机制；③从数量/价格到利润、现金、每股价值的可复算桥梁；④历史时点、预期差和估值；⑤对竞争解释、样本偏差及样本外表现的检验；⑥业务、融资、流动性风险及明确研究动作。新版对①②和部分③提供实物；④没有历史一致预期；⑤只有小样本探索；⑥有压力测试规则，但尚无可执行仓位模型。**可以做机构研究 DEMO，不足以授权实盘自动投资。**

## 必须拆开的四层命题

1. 会计/经营恒等式：计费 GPU 小时 × 净价 + 服务费 = 分部收入；现金变动由经营、投资和融资现金流构成。数据口径正确时无需用股价相关性证明恒等式。
2. 经济机制：客户付费增长是否增加外采算力、哪家供应商拿到订单、何时验收、续约价格能否覆盖折旧与资金成本。每条是可证伪的条件命题。
3. 市场定价：新增信息相对市场原先预期是否改善未来每股现金流，是否被更高贴现率/稀释抵消。增长水平并不等于新信息。
4. 可投资性：信息公开后是否仍有可捕捉收益，且能覆盖成本、冲击、借券及拥挤风险。当前事件检验只触及第3/4层的一小部分，不能用它否定第1层。

## 从 ARR 到股东回报的因果链

客户商业化（M01/M02） → 付费任务/Token（M03） → 每任务 Token 与缓存/吞吐（M14/M15/M22） → GPU 小时需求 → 外采份额/芯片路线/供应商归属（M05/M21/M29） → 签约与实际验收（M06/M07/M09） → 计费小时 × 净租价（M08/M13） → 毛利、维护资本开支、营运资本（M16/M19/M25） → 自由现金流与融资稀释（M10/M17/M18/M27） → 相对于市场预期的每股价值（M30）。

共同原因包括企业 AI 预算、利率、风险偏好、GPU 供需、融资周期。ARR 公告常伴融资/产品发布；股价也会提前交易预期。相关性不能隔离这些共同原因，也不能证明箭头方向。

一个有用的数量桥：[新增] GPU小时需求 ≈ 付费任务 × 每任务未缓存等效Token ÷ 同质量约束下Token/GPU小时。云商收入 ≈ 可用GPU × 期间小时 × 计费利用率 × 合同净价 + 服务收入。必须先核对分母是否已含利用率，避免再乘一次 U。Anthropic run-rate 不能直接代替付费Token，更不能直接代替 NBIS 收入。

## 动作与指标配合：不用“红绿灯买卖”

**需求卡改善、交付卡不动：** 更新潜在需求范围，不提前确认收入。Anthropic 2026年5月融资披露同时提到 AWS、Google/Broadcom TPU、SpaceX 算力；没有供应关系证据就不调高某家 Neocloud 份额。

**合同改善、资金卡恶化：** 调高未来收入可能同时降低每股价值。用月度融资桥计算增发规模：资金缺口/假设发行价 = 新增股数；企业价值增长和每股价值增长分开呈现。

**租价上涨、吞吐提升：** 将租价作为云商收益输入，同时作为下游模型商成本输入。若任务价格下降更快，下游未必能持续承担更高租金。看板的传导实验器用显式假设演示，不冒充实际经营模型。

**预付款改善：** 改变现金时点和融资成本，不立即提高确认收入或毛利。延期时核对退款条款及担保责任。

**业务强、股价跌：** 先检查预期差、估值、贴现率、融资稀释及事件混杂；不能机械宣称市场错了。反过来股价上涨也不验证经营假设。

## 实证结论如何使用

以 `data/event-study.json` 和看板“历史检验”为运行结果的唯一数值来源。初次演示截止 2026-10-21，价格截到前一个完成交易日。H1是外部需求信号与组合后续回报；H2是集团同口径收入增长；H3是NBIS实际月收入年化值的增幅，三者不可互换。

初次 H3 的6个增长事件，5日QQQ超额收益与ARR增幅的Spearman=-0.3714，双侧精确置换p=0.4972；留一法范围[-0.7,0.1]，前后半段相关分别-1.0/+0.5，多重检验校正p=1。**尚无正向预测证据，也没有证据证明负向规律。** 同组事件平均5日超额收益-0.61%，bootstrap区间[-5.28%,3.09%]，并不精确。区间假设事件可交换，小样本、时变波动及相关性使其仍不可靠。

H1只有4个新高披露事件，5日等权组合平均超额+13.41%，但仅2个为正，不做显著性推断。样本只涵盖本轮可发现官方页面，不能声称穷尽所有披露。H2仅2个直接披露的同口径环比，不能回归；业务范围变更和缺失不能靠插值消除。所有检验同时展示1/5/20日期限和SMH基准，不选最漂亮结果。

这些是公告后漂移检验：从公告日期之后首个交易日**收盘**起算，刻意不假设能在公告前交易；不是公告即时市场反应，也不是严格策略收益。下一步需要时间戳级首次披露、历史预期与估值、对照事件、项目交付时间序列。必须先积累样本，再讨论分层/市场模型回归和真正时间外验证，不能用6个样本拟合多因子模型。
